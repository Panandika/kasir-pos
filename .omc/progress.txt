## Codebase patterns observed (carry forward)
- Avalonia 12 supports BOTH ResourceDictionary.ThemeDictionaries (canonical) AND nested <Styles ThemeVariant="X"> (alternative). Both work; we used ThemeDictionaries.
- Inter font already provided via Avalonia.Fonts.Inter NuGet -- no manual bundling needed.
- StockColorConverter caching pattern: lazy init + ActualThemeVariantChanged subscription is the load-bearing perf fix for 24K-row hot path.
- ThemeService startup order: LoadAndApplyAtStartup() MUST be called before MainWindow=new ShellWindow() to avoid unstyled flash.
- Lucide.Avalonia 0.2.5 uses `Kind=` property (not `Icon=`); enum is LucideIconKind.
- Some Lucide icon names differ from web Lucide: `Moon` -> `MoonStar`, `Sun` -> `SunMedium`, `BarChart3` -> `ChartBar`.
